# Keyboard and pointer

| Key | Action |
|-----|--------|
| `+` or `=` | Zoom in |
| `-` | Zoom out |
| `F` | Fit the yard in view |
| `H` | Hide or show menus |
| `B` | Toggle the plan sheet |
| `K` | Toggle the CHOAM kit |
| `R` | Rotate the selected piece |
| `Delete` / `Backspace` | Remove the selected piece |
| `Esc` | Clear selection, close overlay |
| `Ctrl+Z` / `Cmd+Z` | Undo |

Pointer:

- Drag the sand to orbit (OrbitControls)
- Scroll / pinch to zoom
- Click a piece to inspect
- With a kit piece selected, click the yard to place
